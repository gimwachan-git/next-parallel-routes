# `autoShimSlots` example

Demonstrates **auto-generated Group 2 fallback shims**. You write only each
parallel slot's `default.tsx`; the plugin generates the sibling
`[...slug]/page.tsx` for you at build time.

## What you write

```
app/
├─ layout.tsx                  receives @breadcrumbs + @sidebar slots
├─ page.tsx / default.tsx
├─ account/page.tsx           → /account/
├─ account/info/page.tsx      → /account/info/
├─ @sidebar/
│  └─ default.tsx              ← has an import (renders <SidebarNav/>)
└─ @breadcrumbs/
   └─ default.tsx              ← no imports (returns null)
components/sidebar-nav.tsx
```

And in `next.config.ts`:

```ts
export default withParallelRoutes(nextConfig, {
  paths,
  autoShimSlots: ['@sidebar', '@breadcrumbs'],
})
```

Note there is **no** `@sidebar/[...slug]/page.tsx` or
`@breadcrumbs/[...slug]/page.tsx` in the source tree.

## What the plugin generates

On `next build` / `next dev`, the plugin writes one `[...slug]/page.tsx` per
slot, picking a template based on whether `default.tsx` has top-level imports.

`@sidebar/default.tsx` **has an import** → re-export shim:

```tsx
// app/@sidebar/[...slug]/page.tsx
// AUTO-GENERATED by next-parallel-routes — do not edit
// Source: @sidebar/default.tsx
// To customise, edit default.tsx (and/or add a slot-specific page.tsx)
import { staticParamsFromConfig } from 'next-parallel-routes/macro'
import Default from '../default'

export const dynamicParams = false
export const generateStaticParams = staticParamsFromConfig()
export default Default
```

`@breadcrumbs/default.tsx` **has no imports** → inline shim:

```tsx
// app/@breadcrumbs/[...slug]/page.tsx
// AUTO-GENERATED by next-parallel-routes — do not edit
// Source: @breadcrumbs/default.tsx
// To customise, edit default.tsx (and/or add a slot-specific page.tsx)
import { staticParamsFromConfig } from 'next-parallel-routes/macro'

export const dynamicParams = false
export const generateStaticParams = staticParamsFromConfig()

export default function BreadcrumbsCatchAll() {
  return null
}
```

These files are:

- **idempotent** — regenerated only when content differs from `default.tsx`;
- **never overwritten if hand-written** — a `[...slug]/page.tsx` without the
  `AUTO-GENERATED` header is treated as your Group 1 / Group 3 code and left
  alone;
- **git-ignored in this example** (see `.gitignore`) since they are derived
  artifacts. In your own app you can either commit them or enable
  `transientShim: true` (deletes them on exit + auto-manages `app/.gitignore`).

## Run

From the **repo root**:

```bash
pnpm install
pnpm --filter next-parallel-routes-example-auto-shim build
```

After the build, look at `app/@sidebar/[...slug]/page.tsx` and
`app/@breadcrumbs/[...slug]/page.tsx` — they were created by the plugin.
